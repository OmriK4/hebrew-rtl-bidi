# hebrew-rtl-bidi
<div dir="rtl">

הוא עובד באפליקציית הדסקטופ וב-VS Code, ב-Mac וב-Windows.
הוא מוסיף כללי כתיבה לכל סשן, ובודק כל תשובה. הבדיקה עצמה לא צורכת טוקנים, ורק תיקון צורך.
הכללים גם מבקשים מהמודל לחשוב באנגלית ולענות בעברית.

הממשק קובע את כיוון השורה לפי האות הראשונה שלה. שורה שנפתחת במילה באנגלית מוצגת משמאל לימין, והעברית שבה מתבלגנת.

## התקנה

לפני הכול צריך `git` מותקן במחשב, כי Claude Code מושך את הפלאגין מ-GitHub בעזרתו.
ב-Windows מתקינים אותו פעם אחת, ב-PowerShell:

```powershell
winget install --id Git.Git -e
```

אם `git` כבר מותקן, מוודאים שהוא בגרסה העדכנית ביותר. ב-Windows מעדכנים ב-PowerShell:

```powershell
winget upgrade --id Git.Git -e
```

אחר כך סוגרים את VS Code או את הטרמינל לגמרי ופותחים מחדש. אם עדיין לא עובד, מפעילים מחדש את המחשב.

### התקנה ב-VS Code

1. בחלונית של Claude Code מקלידים את הפקודה `/plugins`. נפתח מסך **Manage plugins**.
2. בלשונית **Marketplaces** מוסיפים את הכתובת `OmriK4/hebrew-rtl-bidi`.
3. בלשונית **Plugins** לוחצים **Install** ליד `hebrew-rtl-bidi`, ובוחרים התקנה למשתמש (User).
4. פותחים שיחה חדשה.

אפשר גם לפתוח את מסך ההתקנה ישירות. מדביקים בשורת הכתובת של הדפדפן:

<div dir="ltr">

```text
vscode://anthropic.claude-code/install-plugin?plugin=hebrew-rtl-bidi&marketplace=OmriK4/hebrew-rtl-bidi
```

</div>

### התקנה בטרמינל

מריצים פקודה אחת:

```bash
claude plugin install hebrew-rtl-bidi --marketplace OmriK4/hebrew-rtl-bidi
```

אחר כך פותחים סשן חדש. פלאגין שהותקן כך זמין גם באפליקציית הדסקטופ וגם ב-VS Code באותו מחשב.

אם הפקודה לא עובדת, כנראה הגרסה שלך ישנה. מריצים בשני שלבים:

```bash
claude plugin marketplace add OmriK4/hebrew-rtl-bidi
claude plugin install hebrew-rtl-bidi@omrik4
```

בתוך סשן של Claude Code אפשר להקליד את אותן פקודות עם `/plugin` בהתחלה:

<div dir="ltr">

```text
/plugin marketplace add OmriK4/hebrew-rtl-bidi
```

```text
/plugin install hebrew-rtl-bidi@omrik4
```

</div>

## דרישות

- הכלי `git`, כפי שמוסבר למעלה.
- גרסה `2.1.292` ומעלה של Claude Code, בשביל ההתקנה בפקודה אחת בטרמינל.
- ב-Windows ההוקים רצים ב-Git Bash, עם ה-Perl שמגיע עם Git for Windows.
- אם ההוקים רצים אצלך ב-Windows PowerShell במקום ב-Git Bash, ברירת המחדל שם חוסמת הרצת סקריפטים, והבדיקה בסוף התשובה עלולה לא לרוץ. הכללים והתזכורת ממשיכים לעבוד.
- אין צורך ב-Node או ב-Python. הפלאגין לא תלוי בכלום מעבר למה שהמערכת כבר נותנת.

## המלצה משלימה

מוסיפים לקובץ <code dir="ltr">~/.claude/settings.json</code>, בתוך הסוגריים המסולסלים החיצוניים, את ההגדרה הרשמית של Claude Code:

```json
"language": "hebrew"
```

הפלאגין מחזק את ההגדרה הזו ולא מחליף אותה.

## איך זה עובד

שלוש שכבות, וכל אחת מכסה חולשה של הקודמת:

- בתחילת כל סשן, ושוב אחרי דחיסה של השיחה, מוזרקים כללי הכתיבה המלאים.
- עם כל הודעה שנשלחת מוזרקת תזכורת קצרה, כדי שהשיחה לא תחליק בהדרגה לאנגלית.
- כש-Claude מסיים תשובה, סקריפט קטן בודק אותה. אם היא תקינה, הוא שקט ולא צורך טוקנים.

הבדיקה בסוף התשובה מזהה שלושה מצבים, ובכל אחד מהם Claude מתבקש לתקן פעם אחת:

- כל התשובה באנגלית. מתבקשת כתיבה מחדש של כולה בעברית.
- שורות שהן משפטים שלמים באנגלית בתוך תשובה בעברית. מתבקשת כתיבה מחדש של השורות האלה בלבד.
- שורות עם עברית שנפתחות במילה באנגלית. מתבקשת כתיבה מחדש שלהן, כשהן נפתחות במילה עברית.

בלוקי קוד, קוד בתוך שורה, כתובות וכותרות של קישורים לא נחשבים טקסט באנגלית.
שורה שנפתחת בקוד ויש בה עברית עדיין נחשבת שורה שנפתחת באנגלית.
טקסט שחייב להישאר באנגלית, כמו מייל או הודעת `commit` שביקשת, Claude מתבקש לשים בבלוק קוד.
בניסוי שערכנו התיקון הגיע ל-Claude, ולא הופיעה הודעת שגיאה.

הוק מריץ פקודות במחשב שלך, עם ההרשאות שלך. בגלל זה הקוד פתוח וקצר, ברישיון MIT, וכדאי לקרוא אותו לפני ההתקנה.
ארבעה קבצים מספיקים:

- רישום ההוקים נמצא ב-`hooks/hooks.json`.
- הכללים שמוזרקים כתובים ב-`src/session-start.txt`.
- הבדיקה בסוף התשובה נמצאת ב-`hooks/stop-check.pl`.
- הגרסה של אותה בדיקה ל-PowerShell נמצאת ב-`hooks/stop-check.ps1`.

## התנגשויות

אם כבר יש לך הוק משלך שמבקש עברית, או הוראת שפה ב-`CLAUDE.md`, הפלאגין ימשיך לעבוד.
אבל שני מקורות שמזריקים כללים דומים סתם מבזבזים טוקנים. מומלץ להסיר את ההוק הישן ואת ההוראה הכפולה.

## מגבלות ידועות

- תשובה שנתפסה כבר מוצגת על המסך, והגרסה המתוקנת מופיעה מיד מתחתיה. הוק לא יכול להסתיר הודעה או להחליף אותה.
- הבדיקה רואה רק את ההודעה האחרונה בתור. שורות התקדמות קצרות בין פעולות מכוסות רק על ידי התזכורת.
- הפלאגין מבקש מהמודל לחשוב באנגלית, אבל אף הוק לא רואה את החשיבה ולא יכול לאכוף את זה.
- שאלות עם כפתורי בחירה לא נבדקות.
- שורה שנפתחת במילה עברית ואז ממשיכה כולה באנגלית לא נתפסת.
- הכללים מותאמים לאפליקציית הדסקטופ ול-VS Code. בטרמינל התצוגה עשויה להיות שונה.
- ב-Windows, אם ההוקים רצים ב-PowerShell, הבדיקה בסוף התשובה עלולה לא לרוץ. ברירת המחדל של PowerShell חוסמת סקריפטים, והפלאגין לא עוקף אותה. הכללים והתזכורת ממשיכים לעבוד.
