סיכום השינויים בענף `feature/dark-mode`:

- הוספתי מתג מצב כהה בכותרת האתר.
- המצב נשמר ב-`localStorage`, כך שהבחירה נשארת אחרי רענון.
- עדכנתי את משתני הצבע בקובץ `globals.css`.
- הוספתי בדיקה שמוודאת שהמתג משנה את הערך של `data-theme`.

הנה השינוי המרכזי בקובץ הסגנונות:

```css
:root {
  --bg: #ffffff;
  --text: #1a1a1a;
}

:root[data-theme="dark"] {
  --bg: #121212;
  --text: #f2f2f2;
}
```

כל הבדיקות עוברות. אם תרצה, אפשר להוסיף גם זיהוי אוטומטי של העדפת המערכת.
